# Checklist livraison DA

Avant de demander une intégration tokens :

- [ ] Export Tokens Studio au format DTCG JSON.
- [ ] Tenant id stable fourni.
- [ ] Lien Figma source fourni.
- [ ] Capture ou preview de référence fournie.
- [ ] Modes light/dark précisés.
- [ ] Tokens sémantiques fournis, pas uniquement des palettes primitives.
- [ ] États default, hover, active, focus, disabled, invalid, loading couverts.
- [ ] Aucun CSS ciblant `.fxp-*` ou le markup interne.
- [ ] Changelog court fourni.
- [ ] Contrastes critiques vérifiés côté maquette.
